# Muath Al-Mutairi · Portfolio

[Visit the portfolio](https://muath-al-mutairi.github.io/)

A bilingual personal site for Muath Al-Mutairi. It presents selected projects, technical skills, training, a downloadable CV, and a direct email contact. The site uses plain HTML, CSS, and JavaScript and is hosted on GitHub Pages.

To preview locally, run `python -m http.server 8000` in the repository and open `http://localhost:8000/`. The site defaults to Arabic. Append `?lang=en` to link directly to English.

The project card links to the [public OmniCore showcase](https://github.com/Muath-Al-Mutairi/OmniCore-Fall-Detection). Team OmniCore's project materials are subject to its [ownership notice](https://github.com/Muath-Al-Mutairi/OmniCore-Fall-Detection/blob/main/COPYRIGHT.md).
